How LOWESS works

Instead of one equation for all data, LOWESS fits a separate tiny regression at every point. Nearby points get more influence (weight) than distant ones.

The frac parameter controls what fraction of the data each local fit considers. Small frac = flexible/wiggly curve that tracks local patterns. Large frac = smoother curve that behaves more like ordinary linear regression.

Try: set frac=1.0 and watch the curve become a straight line — because every local fit now uses ALL the data.

How Polynomial regression works

Fits one equation y = a₀ + a₁x + a₂x² + … to all data at once. The degree controls how many bends the curve can have.

Overfitting: when degree approaches n−1, the curve passes through every point perfectly (R² = 1) but wobbles wildly between them. It memorized the noise instead of learning the pattern.

Try: crank degree to max, then add a few more points and watch the fit completely change shape.

What is bootstrapping / the confidence band?

Bootstrapping resamples your data with replacement many times, fits the model to each resample, and shows the spread of results as a shaded band.

The band represents a 95% confidence interval — where the fit would likely land if you collected slightly different data. A wide band means the fit is uncertain in that region; narrow means it is stable.

Set bootstrap samples to 100+ and notice how the band is wider at the edges where there is less data.
