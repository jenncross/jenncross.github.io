How does min-max normalization work?
For each feature, find the minimum and maximum values across all data points. Then transform each value: x_norm = (x - min) / (max - min). This maps the smallest value to 0 and the largest to 1. Both features now live on the same scale, so Euclidean distance treats them equally.

What do the confusion matrix cells mean?
True Positive (TP): Predicted A, actually A — correct.
True Negative (TN): Predicted B, actually B — correct.
False Positive (FP): Predicted A, actually B — error (Type I).
False Negative (FN): Predicted B, actually A — error (Type II).

Accuracy = (TP + TN) / total test points.

How does kNN work?
1. Calculate distances from the query point to every training point using Euclidean distance: d = sqrt((x1-x2)^2 + (y1-y2)^2).

2. Sort distances to find the k smallest (this is what argsort does in Python).

3. Count classes among those k nearest neighbors.

4. Vote: the majority class wins. The query point is assigned that class label.
What does k control?
k = 1 (nearest neighbor): The query point copies its single nearest neighbor. Classification is very sensitive to individual points — moving the query slightly can flip the result.

k = large: More neighbors vote, so the classification is smoother and less affected by any single outlier. But it becomes less responsive to local patterns in the data.

Using an odd k avoids ties when you have two classes.

Why does this happen?
Euclidean distance is calculated as sqrt((x1-x2)^2 + (y1-y2)^2). When Feature 1 ranges from 0 to 100 and Feature 2 ranges from 0 to 2, a difference of 10 in Feature 1 contributes 100 to the squared distance, while a difference of 1 in Feature 2 contributes only 1. Feature 1 effectively controls the distance calculation all by itself.

After min-max normalization, both features range from 0 to 1, so equal-sized differences in either feature contribute equally to the distance. The classifier can now use information from both features to make its decision.
