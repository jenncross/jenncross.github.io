How does median filtering work?

The median filter slides a window across the signal one sample at a time. At each position it sorts the values inside the window and picks the middle value (the median) as the output.

Outlying spikes get replaced by the median of their neighbors, which smooths out high-frequency noise while preserving the shape of the underlying signal. In Python, scipy.signal.medfilt does this.

Try: Set window to 3 (minimal), then increase to 21 and watch the noisy sine wave become smoother. Example applications for this kind of signal include pendulum motion, a pedometer, or a breath-rate tracker.

How does Gaussian-weighted smoothing work?

Instead of treating all window values equally, Gaussian smoothing applies weights shaped like a bell curve. The center value gets the highest weight and values farther from center contribute less.

In Python, generate weights with scipy.signal.gaussian and apply them with numpy.convolve.

Try: Watch the weight values inside the window as the filter steps through.

What are high-frequency vs. low-frequency signals?

A signal is a composite of components that change at different rates. Low-frequency components change slowly (like the main sine-wave trend). High-frequency components change rapidly (like noise spikes).

Smoothing filters are low-pass filters: they let low frequencies pass and remove high frequencies. The window size controls the cutoff.

The signal-to-noise ratio (SNR) describes how much "good" signal you have relative to noise. High SNR = clean. Low SNR = buried in noise.

How do zero crossings find periods?

For a sine-wave-like oscillation, one cycle later the signal rises through zero again. The time between consecutive rising zero crossings is the period.

We smooth first so random noise does not create extra crossings.

Example applications include a pendulum motion sensor, a pedometer-style repeating motion signal, or a breath-rate tracker.

Where might this be useful?

This works well for signals that are roughly sinusoidal. Example applications include a pendulum motion signal, a pedometer-like repeating motion signal, or a breath-rate tracker. By contrast, the EKG examples in the next two tabs have sharp spikes and are better handled with peak finding.

How does peak detection work?

The algorithm scans left to right. At each point it checks: (1) Is this a local maximum (higher than both neighbors)? (2) Is it above the threshold?

If both are true the point is a candidate. Then: is it at least min_distance samples from the last accepted peak? If yes, accepted (green). If too close, rejected (red).

The period is the spacing between consecutive peaks. A stable average period means a consistent rhythm like a heartbeat.

Why can noise cause trouble?

Noise creates false local maxima. A small random spike can trick the algorithm into looking like a heartbeat peak.

That is why the threshold and minimum peak distance matter. They help reject many noisy spikes without changing the underlying signal first.

Why use a median filter here?

A long-window median filter follows the slow baseline drift but ignores the narrow R peaks better than a moving average does. That makes it a good simple baseline estimate.

What is the correction step?

First estimate the baseline with a long median filter. Then compute corrected = raw - baseline. After that, the same threshold peak detector works much better.
